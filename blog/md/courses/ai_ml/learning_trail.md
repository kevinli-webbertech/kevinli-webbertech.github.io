# Machine Learning Learning Trail

Follow these three steps in order. The trail moves from machine-learning foundations to large-language-model concepts and then to a working application.

## 1. Learn the Foundations

Read [IBM's Guide to Machine Learning](https://www.ibm.com/think/machine-learning) to understand the basic ML workflow, including supervised learning, unsupervised learning, deep learning, feature engineering, model training, and MLOps.

**Checkpoint:** Explain the difference between supervised and unsupervised learning, and identify one task each is suited to solve.

## 2. Connect ML to Large Language Models

Study the course [LLM Overview & Comparison](https://kevinli-webbertech.github.io/blog/html/courses/ai_ml/llm_overview.html). Focus on the Transformer model, context windows, model evaluation, and the differences between open-weight and hosted models.

**Checkpoint:** Select one model for a small application and state why its context window, cost, or deployment model fits the use case.

## 3. Build a Small AI Application

Complete the [Qwen Small App Example](https://kevinli-webbertech.github.io/blog/html/courses/ai_ml/qwen_small_app_example.html). Configure the environment variables, run the Streamlit chat application, and test at least three prompts.

**Checkpoint:** Capture the running app and write a short note describing how the API key, base URL, model ID, and prompt history are used.

## Suggested Pace

| Step | Activity | Estimated time |
|---|---|---:|
| 1 | IBM machine-learning guide and notes | 60-90 minutes |
| 2 | LLM overview and model-selection notes | 60 minutes |
| 3 | Qwen Streamlit app setup and testing | 90-120 minutes |

> Complete the trail in sequence. It is educational material and does not replace the course assignments or project requirements.
