# Machine Learning - Learning Trail

A curated list of external tutorials to reinforce the concepts covered in this course. Work
through these alongside the course material; they are not a replacement for the lecture notes
in [ml_intro.md](./ml_intro.md), [classic_ml_intro.md](./classic_ml_intro.md), and
[scikit-learn.md](./scikit-learn.md).

## Suggested Resources

- [Machine Learning (ML) Tutorial](https://www.tutorialspoint.com/machine_learning/index.htm) —
  TutorialsPoint's overview of ML concepts: types of learning, common algorithms, and a
  walkthrough of the end-to-end ML workflow.
- [Python Machine Learning](https://www.w3schools.com/python/python_ml_getting_started.asp) —
  W3Schools' introductory series on using Python for machine learning, covering basic statistics
  and getting started with data in Python before moving into modeling.
