# Mac OS Howto

This guide covers some basic things to get comfortable with on macOS, such as installing
software from a `.dmg` file and finding your way around an application's own menu bar.

## Installing software from a DMG file

Most macOS applications are distributed as `.dmg` (disk image) files. Installing from a
DMG usually works like this:

1. Download the `.dmg` file from the vendor's website.
2. Double-click the downloaded file. This mounts a virtual disk and opens a Finder window.
3. Drag and drop the application icon onto the `Applications` folder shortcut shown in
   that same window.
4. Eject the mounted disk image once the copy is complete.
5. Launch the application from `Applications` or Launchpad.

## The application menu bar

Every macOS app has its own menu bar at the top of the screen, to the right of the Apple
menu (). The menu items (File, Edit, View, Window, Help, etc.) change depending on which
app is currently active/focused, and are different from the system-wide Apple menu.

## Homework

1/ Search Google for "Visual Studio Code download" and download the macOS `.dmg` file.
If you already have Visual Studio Code installed, you can still double-click the DMG
file to see how the installer window looks, and practice dragging and dropping the
Visual Studio Code icon onto the `Applications` folder shortcut.

2/ Open another piece of software that comes with your Mac, such as `Photos`, `iMovie`,
or `iTunes`/`Music`. Click through that application's **own** menus (not the Apple menu
on the far left) and take note of what options are available in each menu (e.g., File,
Edit, View, Window, Help).
